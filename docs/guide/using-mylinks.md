# Using MyLinks

## Collections

A collection groups related links — by project, by topic, or however you organize your own bookmarks. A link can belong to several collections at once.

Every account has one collection you cannot delete: the **Inbox**. It is where a link lands when it is saved without an explicit collection, and where a link falls back to if the last collection holding it is deleted.

Each collection has a visibility:

- **Private** — visible only to you.
- **Public** — reachable by anyone with the link, no account required on their end. See [Sharing](#sharing).

## Links

A link has a name, an optional description, a URL, and the collections it belongs to. Marking a link as a favorite pins it to the **Favorites** view.

Opening a link goes through a redirect that counts the click. Clicks are what rank your most-used links first — the more you actually open something, the higher it surfaces.

## Search

Full-text search covers both collections and links, matching on name and URL. It is available from anywhere in the app, and from the browser extension's panel with a keyboard shortcut — see [Browser extension](/guide/browser-extension).

## Sharing

Any collection set to **Public** gets a single shareable URL. Anyone who opens it can browse the collection's links without signing in. Making a collection private again immediately closes that URL to anyone but you.

## Export and import

Your links export as plain JSON at any time, from your account settings. The same page accepts that JSON back in, so moving between instances — or just keeping an offline copy — never depends on MyLinks staying available.
